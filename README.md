# rcfiles

Configuration files for various Unix programs. Intended for MacBook setup.

Run `init.sh` to symlink files to their correct location.

- `.shell_aliases`
	- shared config for e.g. bash/zsh
- `.gitconfig`
	- [Git](https://git-scm.com/)
- `.gitignore`
	- default .gitignore with common nuisance files
- `.hgrc`
    - [Mercurial](https://www.mercurial-scm.org/) config
- `.inputrc`
    - GNU [readline](https://man7.org/linux/man-pages/man3/readline.3.html) config for interactive shells
- `.Rprofile`
	- [R](https://www.r-project.org/), runs on session start
- `.screenrc`
	- [screen](https://www.gnu.org/software/screen/manual/screen.html)
- `.tmux.conf`
	- [tmux](https://tmux.app/)
- `.vimrc`
	- [Vim](https://www.vim.org/)
- `spell`
	- spell files for Vim spellchecking
- `Library/KeyBindings/DefaultKeyBinding.dict`
	- MacOS key remaps
- `mpv.conf`
	- [mpv](https://mpv.io/) media player
